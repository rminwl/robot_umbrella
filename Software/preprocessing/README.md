# 풍향·풍속 전처리 및 리브 제어 (wind_preprocess)

캡스톤 **"환경적응형 웨어러블 로봇 우산"** 의 센서 전처리와 모터 제어 코드입니다.

몸에 단 풍속계와 풍향계로 바람을 10 Hz로 측정해 정제한 다음, 바람이 불어오는 쪽 리브를 내려 비를 막도록 **리브 4개, 관절 8개(다이나믹셀)** 를 움직입니다. 바람이 너무 세면 리브를 접는 **강풍 안전 모드**로 들어갑니다.

```
센서 원시값 → 정제된 바람 특징값(WindFeatures) → 리브 8관절 목표각(RibTargets) → 다이나믹셀 8개
```

## 파일 구성

| 경로 | 설명 |
|---|---|
| `wind_preprocess/wind_preprocess.ino` | **메인 펌웨어 (ESP32).** 센서 판독 → 전처리 → 관절 각도 계산 → 다이나믹셀 전송 → CSV 출력 |
| `wind_logger.py` | **PC 쪽 도구.** 시리얼 CSV 수집, 분석·시각화, 학습용 특징 생성, 매핑 검증 |
| `anemo_test/anemo_test.ino` | 풍속계 단독 확인용 스케치 (배선·리드 스위치·채터링 점검) |
| `docs/wind_preprocess_report.md` | 알고리즘 상세 보고서 (흐름도, 단계별 설명, 한계점 9개) |

## 하드웨어

| 구분 | 내용 |
|---|---|
| MCU | ESP32-DevKitC (Arduino IDE, arduino-esp32 core 3.x) |
| 센서 | SparkFun Weather Meter (SEN-15901) 풍속계 + 풍향계 |
| 모터 | 다이나믹셀 8개 (XL330 또는 XL430, **미확정**). ESP32에 직접 연결 |

| 핀 | 용도 |
|---|---|
| GPIO27 | 풍속계 리드 스위치 (GND와 연결, 내부 풀업) |
| GPIO34 | 풍향계 전압 분배 출력 (3.3 V 쪽 10 kΩ 풀업) |
| GPIO0 | 캐노피 모드 버튼 (BOOT 버튼) |
| GPIO17 / 16 | Serial2 TX / RX → 반이중 버퍼(예: 74LVC2G241) → 모터 DATA |
| GPIO4 | 반이중 방향 제어 (HIGH = 송신) |

**모터 ID**: Top_L J1/J2 = 1/2, Top_R = 3/4, Side_L = 5/6, Side_R = 7/8

## 빠른 시작

### 1. 펌웨어

1. Arduino IDE 라이브러리 매니저에서 **Dynamixel2Arduino**를 설치합니다.
2. 보드 **ESP32 Dev Module**을 선택하고 `wind_preprocess/wind_preprocess.ino`를 업로드합니다.
3. 시리얼 모니터(115200)에서 다음 두 가지를 확인합니다.
   - `# TEST ... PASS` (자가 테스트)
   - `# DXL 8 motor(s) found`

모터 없이 센서만 시험하려면 `USE_DXL = false`로 바꿔 업로드합니다.

### 2. PC

```bash
pip install pyserial pandas numpy matplotlib
python wind_logger.py selftest                       # 매핑 검증 (펌웨어 자가 테스트 표와 비교)
python wind_logger.py log --port COM5                # 수집 → logs/wind_YYYYMMDD_HHMMSS.csv (Ctrl+C 종료)
python wind_logger.py log --port COM5 --duration 300 # 300초만 수집
python wind_logger.py analyze logs/wind_20261119_153000.csv
```

### 3. 런타임 조작

| 입력 | 동작 |
|---|---|
| 시리얼 `h` | CSV 헤더 재출력 |
| 시리얼 `w` / `n` | WIDE(넓게) / NARROW(좁게) 모드 |
| BOOT 버튼 | 모드 토글 |

## 알고리즘 요약

10 Hz(100 ms)마다 아래 순서로 처리하고, CSV는 5 Hz로 출력합니다.

1. **풍속**: 리드 스위치 펄스 간격으로 순간 풍속을 구합니다(1 Hz = 0.667 m/s). 10 ms 디바운스를 적용합니다.
2. **풍향**: 전압 → 저항으로 역산하고, 16방위 저항표에서 log 거리가 가장 가까운 방향을 고릅니다. 단락, 미연결, 표 밖 값은 무효로 처리합니다.
3. **센서 고장**: 풍향 무효가 2초 넘게 이어지면 `sensor_fault`가 되고 중립 자세로 갑니다.
4. **평활**: 각도가 아니라 **풍속을 곱한 벡터 (u, w)** 를 EMA(τ = 1초)로 평균합니다. 여기서 평균 풍향과 **안정도 R**(0~1)을 구합니다.
5. **돌풍**: 1초 평균 풍속의 최근 10초 최대값입니다.
6. **방향 유효 판정**: 무풍(< 1.0 m/s), 불안정(R < 0.3), 센서 고장이 모두 아니어야 유효합니다. 각 판정에는 히스테리시스가 있습니다.
7. **기울기**: `atan(풍속 / 6 m/s)`, 최대 30°입니다(빗줄기 기울기).
8. **강풍 모드**: `max(평균 풍속, 돌풍) > 10 m/s`이면 들어가고, 8.5 m/s 미만이 5초 유지되면 해제됩니다.
9. **관절 매핑**: 리브마다 `c = cos(리브 방향 − 풍향)`을 구합니다. 바람 쪽 리브(c > 0)는 내리고, 반대쪽은 살짝 올립니다. 그다음 2° 데드밴드와 속도 제한(J1 60°/s, J2 90°/s)을 적용합니다.
10. **전송**: 8관절 각도를 tick으로 바꿔 **Sync Write 1패킷**으로 보냅니다.

**각도 규약**: 풍향 = 바람이 **불어오는** 방향. 사용자 정면 0°, 위에서 볼 때 시계방향 증가 (90° = 오른쪽에서 불어옴).

## ⚠️ 주의사항

### 전원·배선

- **모터 전원을 먼저 켜고, 그다음 ESP32를 켜세요.** 모터는 부팅할 때 한 번만 찾습니다. 그때 응답하지 않은 모터는 ESP32를 다시 켜기 전까지 **움직이지 않습니다.** 그런데도 CSV에는 관절 값이 정상처럼 찍히니, 부팅 로그의 `# DXL ... NOT FOUND` 줄을 꼭 확인하세요.
- 모터 전원(XL330 5 V / XL430 11.1 V)은 ESP32와 **따로 공급**하고, **GND는 반드시 공통으로** 묶습니다.
- 모터 전원은 그대로 두고 ESP32만 리셋하면, 초기화하는 동안 잠깐 토크가 풀려 리브가 처질 수 있습니다.
- 풍향계 ADC 핀은 GPIO34(ADC1)입니다. 다른 핀으로 옮길 때는 ADC1 핀을 쓰세요.

### 안전

- **풍속계가 단선되거나 고장 나도 감지하지 못합니다.** 펄스가 없으면 무풍으로 보기 때문에 **강풍 모드가 동작하지 않습니다.** 시험 전에 `anemo_test`로 풍속계를 확인하세요.
- 강풍 모드 진입과 안전 자세 완성까지 돌풍 시작 후 **약 1.3초**가 걸립니다.
- **모터 상태를 읽지 않는 개방 루프 구조입니다.** 과부하로 모터가 셧다운되거나 재부팅되어도 펌웨어는 모릅니다. CSV의 `r*_j*`는 **실제 자세가 아니라 지령값**입니다.
- 강풍 한계 10 m/s는 초기값입니다. 리브·관절 강도 시험 결과에 맞춰 조정해야 합니다.

### 코드 수정 시

- 조정값은 모두 `wind_preprocess.ino` 상단 **"1. 파라미터"** 절에 모여 있습니다.
- **`wind_logger.py` 상단에도 같은 값이 복사되어 있습니다.** 리브 방향, 게인, 관절 범위 등을 바꾸면 **두 파일을 함께** 고치세요. 바꾼 뒤에는 펌웨어 부팅 로그의 `# TEST map8` 표와 `python wind_logger.py selftest` 출력이 같은지 확인하세요.
- 모터 영점(`JOINT_ZERO_TICK`)과 방향 부호(`JOINT_DIR_SIGN`)는 조립할 때마다 관절별로 측정해야 합니다. 값이 틀리면 리브가 반대로 움직입니다. 처음에는 **리브를 분리하거나 손으로 받친 상태**에서 확인하세요.
- `DXL_BAUD`를 바꾸면 모터 쪽 Baud Rate도 DYNAMIXEL Wizard로 같이 바꿔야 합니다.

### 측정값 해석

- 센서가 몸에 붙어 있어서 측정값은 **겉보기 바람**(실제 바람 + 걷는 속도)입니다. 몸을 돌리는 것도 풍향 변화로 측정됩니다(반응 지연 약 1~2초).
- 등 뒤(180°) 바람을 막는 리브는 없습니다. 이 방향에서는 윗리브만 살짝 올라갑니다.
- 풍향 순간값의 분해능은 22.5°입니다.

## 미확정 / 실험 후 정할 값

| 항목 | 현재값 | 비고 |
|---|---|---|
| 모터 기종 | XL330 / XL430 | 토크·전원·무게 시험 후 결정 |
| 모터 수 (`JOINT_PRESENT`) | 8개 | 6~8개 예상 |
| 리브 방향 (`RIB_ANGLE_DEG`) | 315 / 45 / 270 / 90° | 설계 이미지 기준 추정값 |
| 옆리브 J1 구조 | 위아래 회전 가정 | 수평 회전이면 매핑 재설계 |
| 장착 오프셋 (`MOUNT_OFFSET_DEG`) | 0° | 장착 후 정면 바람으로 확인 |
| EMA 시정수 (`EMA_TAU_S`) | 1.0 s | 선풍기 시험에서 0.5 / 1.0 / 1.5 s 비교 |
| 강풍 한계 (`WIND_SAFE_LIMIT_MS`) | 10 m/s | 변형 시작 풍속의 70~80% |
| 센서 고장 시 자세 (`FAULT_ACTION`) | 중립 | 안전 우선이면 SAFE |
| 단락 기준 전압 (`VANE_SHORT_MV`) | 180 mV | 실측값으로 재계산 |
