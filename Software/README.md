# ESP32 핀 사용 가이드

이 문서는 현재 저장소의 센서 테스트 코드에서 사용하는 핀과, 일반적인 **클래식 ESP32 (ESP32-WROOM-32 / DevKit 계열)**의 핀 주의사항을 정리합니다. ESP32-S2/S3/C3 및 보드별 변형은 핀 기능이 다를 수 있으므로, 실제 보드의 핀아웃과 모듈명을 먼저 확인하세요.

## 현재 센서 핀 배정

| 신호 | ESP32 GPIO | 코드 | 비고 |
|---|---:|---|---|
| 압전 센서 아날로그 출력 | GPIO34 | [`test/raining_test.ino`](test/raining_test.ino) | 아날로그 입력 전용 핀 |
| 빗물 센서 AO | GPIO35 | [`test/raining_test.ino`](test/raining_test.ino), [`test/ONE028.ino`](test/ONE028.ino) | 아날로그 입력 전용 핀 |

GPIO34와 GPIO35는 클래식 ESP32의 ADC1 입력 핀입니다. ADC1은 Wi-Fi 사용 중에도 ADC2보다 제약이 적어 현재 아날로그 센서 입력에 적합한 선택입니다. 두 센서를 동시에 연결할 때 각 센서의 아날로그 출력은 표에 지정된 서로 다른 핀으로 연결하세요.

## 핀 선택 요약

| 핀 종류 | GPIO | 권장 사항 |
|---|---|---|
| 아날로그 입력(ADC1) | GPIO32–GPIO39 | 아날로그 센서에 우선 고려. 단, GPIO34–GPIO39는 입력 전용 |
| 입력 전용 | GPIO34–GPIO39 | 센서 출력 입력에는 사용 가능. 출력, 내부 풀업/풀다운은 사용할 수 없음 |
| 부트 스트랩 핀 | GPIO0, GPIO2, GPIO5, GPIO12, GPIO15 | 부팅 모드/전압 상태에 영향을 줄 수 있으므로 외부 회로 연결을 피하거나 보드 회로를 확인한 뒤 사용 |
| 플래시 연결 핀 | GPIO6–GPIO11 | 모듈의 SPI 플래시에 연결됨. 사용하지 말 것 |
| 기본 UART 핀 | GPIO1(TX0), GPIO3(RX0) | USB 시리얼 로그/업로드에 쓰일 수 있으므로 센서에 사용하면 충돌할 수 있음 |
| ADC2 핀 | GPIO0, GPIO2, GPIO4, GPIO12–GPIO15, GPIO25–GPIO27 | Wi-Fi와 함께 아날로그 입력으로 쓰면 제약이 생길 수 있음. 아날로그 센서에는 ADC1을 우선 사용 |

일반 입출력 후보로 GPIO18, GPIO19, GPIO21, GPIO22, GPIO23, GPIO25–GPIO27, GPIO32, GPIO33 등을 고려할 수 있지만, 보드 내장 장치나 통신 기능과의 충돌 여부를 보드 핀아웃에서 확인하세요. 위 핀 표는 클래식 ESP32 기준이며 다른 ESP32 계열에 그대로 적용하지 마세요.

## 전기적 주의사항

- ESP32 GPIO는 **3.3V 로직**입니다. 센서 AO나 디지털 출력이 GPIO에 3.3V를 초과해 입력되지 않도록 하세요. 5V로 구동하는 센서 모듈의 AO가 5V까지 올라갈 수 있다면 레벨 시프터 또는 적절한 분압/보호 회로가 필요합니다.
- 압전 소자는 순간적으로 큰 양/음 전압을 만들 수 있습니다. 보호 회로 없이 소자를 GPIO에 직접 연결하지 말고, 저항 및 클램프 등 입력 보호 회로를 사용하세요.
- GPIO34–GPIO39에는 내부 풀업/풀다운이 없습니다. 입력이 떠 있지 않도록 센서 출력과 GND 연결을 확인하고, 필요한 경우 외부 저항을 사용하세요.
- 센서와 ESP32는 공통 GND를 사용해야 합니다. 보드의 3.3V/5V 핀 및 센서 모듈 전원 요구사항은 모듈 사양을 확인하세요.

## 연결 전 확인

1. ESP32 보드의 정확한 모델/핀아웃을 확인합니다.
2. 센서의 AO/DO 출력 전압 범위를 확인하고 GPIO 입력 허용 범위(0–3.3V)를 넘지 않게 합니다.
3. 센서 신호선을 코드의 GPIO 번호와 일치시킵니다.
4. USB 시리얼 로그를 사용하는 동안 GPIO1/3을 다른 용도로 사용하지 않습니다.
5. 전원을 넣기 전에 GND와 전원 극성, 입력 보호 회로를 다시 확인합니다.
